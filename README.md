# IPL-ANALYSIS-DASHBOARD-USING-EXCEL
Interactive IPL Analysis Dashboard (2008–2023) built in Excel using PivotTables, PivotCharts, and slicers for season-wise filtering. Tracks season winners, runner-ups, Player of the Match/Tournament, toss-decision win rates (bat first vs bowl first), top Man-of-the-Match award winners, and a team-wise championship wins treemap.
